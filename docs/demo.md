# 5-minute demo script

1. Open the dashboard and sign in with the demo account.
2. Create a `critical` incident for `payments-api`.
3. Paste logs such as: `POST /checkout -> 504 Gateway Timeout; database connection timeout`.
4. Open the incident and click **Analyze with SentinelAI**.
5. Show the AI summary, root-cause hypothesis, and recommendations.
6. Open a second browser tab to demonstrate real-time WebSocket updates.
7. Mark the incident resolved and show the resolved counter.
8. Open `/docs` on the FastAPI backend to demonstrate the documented API surface.
