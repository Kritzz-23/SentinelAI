## SentinelAI — AI-Powered Real-Time Incident Management Platform
**Tech:** React.js, TypeScript, NestJS, Python, FastAPI, PostgreSQL, Redis, RabbitMQ, WebSockets, Docker, JWT

- Built a production-style incident management platform with JWT authentication, incident lifecycle APIs, severity/status tracking, and a real-time WebSocket dashboard.
- Implemented event-driven incident notifications using RabbitMQ and separated AI intelligence into a FastAPI service for log analysis, root-cause hypotheses, and remediation recommendations.
- Containerized the multi-service stack with Docker Compose and added GitHub Actions CI for backend compilation and frontend builds.
